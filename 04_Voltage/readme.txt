Lazy build for embedding a Phoenix Contact DC voltage level shifter (SCK-M-U-1500V) into a 3D printed case.
These components should be on the board:
 - 24V supply for the Phoenix Contact, power by 5V:  Murata NME0524DC
 - Adafruit ADS1115 breakout board
 - Adafruit PowerBoost 1000 Charger
 - Adafruit ItsyBitys M4 express
 
Embedding everything on a single PCB would be beneficial, but using an industry standard for 1500V string voltages seems reasonable.

DC connection via panel mount plugs (banana or solar connectors).
Power switch, with LED.
USB and SMA antenna plugs recommended.
