# Main Unit
Either use an M5 Stack for control. Or use an USB LoRa adapter, plugged into your computer or smartphone.

- M5 Stack: can be controlled directly via buttons. Or via WLAN (webSocket) GUI.
- USB LoRa adapter:  dongle for LoRa communication, design based on Adafruit ItsyBitsy M4 Express. Can be controlled via USB (webSerial) or Android/iOS application (Flutter). Mounts as an USB stick with index.html accessible (Circuitpython).

NOTE:
M5 Stack fully works and was field tested.
USB LoRa adapter has not been tested. 
It's all there. But adaptations might be necessary.
